VideoCall на GitHub Pages не запускается

GitHub умеет только показать статичные файлы. Для видеозвонков нужен Node.js-сервер (Socket.IO / WebRTC signaling). Поэтому github.io открывает страницу, но звонки не работают.

Опубликуйте приложение на Render (бесплатно) — получите рабочую HTTPS-ссылку для ПК, iPhone и Android.

Открыть рабочее приложение Deploy на Render Репозиторий
  1. Нажмите «Deploy на Render» и войдите через GitHub
  2. Создайте Web Service из этого репозитория (Blueprint подхватит render.yaml)
  3. Дождитесь деплоя и откройте URL вида https://….onrender.com

Телефон: нужен HTTPS

Safari и Chrome на iPhone/Android блокируют камеру и микрофон на обычном HTTP. Запустите сервер командой npm start и откройте на телефоне ссылку Интернет (туннель) или LAN HTTPS из окна сервера — не http://192.168…
