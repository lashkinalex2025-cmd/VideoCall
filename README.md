# VideoCall

Веб-сервис онлайн видеозвонков и видеоконференций для команды.

## Возможности

- **Web + PWA** — работает в браузере, ставится на Android / ПК как приложение
- Адаптивный интерфейс: телефон, планшет, ноутбук, компьютер
- Голос, видео, демонстрация экрана
- Чат: сообщения всем участникам или лично выбранному
- До **100** участников в комнате
- Комнаты **без пароля** и **с паролем**
- Запись конференции на компьютер (WebM)
- Живая **транскрипция** (Chrome/Edge) и **отчёт** по встрече
- Роли и права: хост, со-хост, участник (чат, экран, mute, kick, пароль, блокировка входа)
- Без ограничения длительности конференции

## Важно: GitHub ≠ рабочий сервер

Репозиторий на GitHub хранит код. **GitHub Pages не запускает Node.js**, поэтому
`https://…github.io/VideoCall/` показывает страницу, но **видеозвонки там не работают**.

Для публичной ссылки (ПК + телефон) нужен хостинг вроде **Render**.

### Опубликовать в интернет (Render)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/lashkinalex2025-cmd/VideoCall)

1. Откройте: https://render.com/deploy?repo=https://github.com/lashkinalex2025-cmd/VideoCall
2. Войдите через GitHub и подтвердите создание Web Service
3. Дождитесь деплоя (2–5 минут)
4. Откройте выданный URL — это и есть рабочее приложение

**Рабочая ссылка сейчас:** https://videocall-hfgy.onrender.com

Она же прописана в `public/config.js` (`VIDEOCALL_LIVE_URL`), поэтому на GitHub Pages есть кнопка «Открыть рабочее приложение».

> На бесплатном плане Render сервис «засыпает» без трафика — первый заход может занять ~30–60 секунд.

### Разные сети (не только Wi‑Fi)

Приложение использует **TURN** (Open Relay), чтобы участники с мобильного интернета и разных Wi‑Fi видели друг друга.  
Камеру/микрофон на телефоне нужно разрешить при нажатии «Присоединиться» / «Создать» (требование iOS/Android).

### Регистрация и кабинеты

На главной:
- **Регистрация** — email + пароль + подтверждение → личный кабинет
- **Вход в кабинет** — для пользователей и администраторов
- **Гостевой вход** — по ID и паролю конференции без регистрации

В личном кабинете пользователь может создавать/настраивать конференции и начинать их.

Письмо о новом пользователе уходит на `NOTIFY_EMAIL` (по умолчанию `lashkinalex2025@gmail.com`).  
Для реальной доставки настройте SMTP (`SMTP_HOST`, `SMTP_USER`, `SMTP_PASS`).

### Кабинет администратора

На главной нажмите **«Кабинет администратора»** (или войдите как `admin`).

По умолчанию:
- логин: `admin`
- пароль: `VideoCall2026`

В кабинете можно:
- создавать/удалять ссылки конференций
- смотреть пользователей и удалять их
- видеть, кто сейчас online в конференциях
- создавать обычных пользователей и администраторов

Смените пароль через `ADMIN_USER` / `ADMIN_PASSWORD`.

## Локальный запуск

```bash
cd VideoCall
npm install
npm start
```

После запуска в консоли появятся ссылки:

- **ПК:** `http://localhost:3000` или `https://localhost:3443`
- **Телефон в той же Wi‑Fi:** `https://ВАШ_IP:3443`

Safari/Chrome на телефоне требуют **HTTPS** (не `http://192.168…`).

## Переменные окружения

Скопируйте `.env.example` при необходимости:

| Переменная   | Описание                                              |
|-------------|--------------------------------------------------------|
| `PORT`      | Порт сервера (по умолчанию `3000`)                     |
| `HOST`      | Хост bind (по умолчанию `0.0.0.0`)                     |
| `XAI_API_KEY` | Опционально: SpaceXAI/xAI для AI-резюме в отчёте    |

## Как пользоваться

1. Создайте комнату (по желанию с паролем) или войдите по ID / ссылке `/?room=ID`
2. Разрешите камеру и микрофон
3. Пригласите коллег ссылкой
4. В панели: чат, участники, транскрипция, права
5. Запись и отчёт скачиваются локально на ваш компьютер

## Стек

- Node.js, Express, Socket.IO (сигналинг и комнаты)
- WebRTC mesh (STUN)
- Progressive Web App (manifest + service worker)
- Web Speech API (транскрипция)
- MediaRecorder (запись)
- Опционально SpaceXAI (`grok-4.5`) для резюме отчёта
