# VideoCall

Веб-сервис онлайн видеозвонков и видеоконференций для команды.

## Возможности

- **Web + PWA** — работает в браузере, ставится на Android / ПК как приложение
- Адаптивный интерфейс: телефон, планшет, ноутбук, компьютер
- Голос, видео, демонстрация экрана
- Чат: сообщения всем участникам или лично выбранному
- До **100** участников в комнате
- Комнаты **без пароля** и **с паролем**
- Запись конференции на компьютер (WebM)
- Живая **транскрипция** (Chrome/Edge) и **отчёт** по встрече
- Роли и права: хост, со-хост, участник (чат, экран, mute, kick, пароль, блокировка входа)
- Без ограничения длительности конференции

## Быстрый старт

```bash
cd VideoCall
npm install
npm start
```

После запуска в консоли появятся ссылки:

- **ПК:** `http://localhost:3000` или `https://localhost:3443`
- **Телефон в той же Wi‑Fi:** `https://ВАШ_IP:3443`
- **iPhone / Android (рекомендуется):** ссылка **Интернет** (HTTPS-туннель) — её и нужно открывать на смартфоне

### Почему на телефоне «не запускалось»

Safari (iPhone) и Chrome (Android) **блокируют камеру и микрофон на HTTP**, если это не `localhost`.  
Адрес вида `http://192.168.x.x:3000` на смартфоне для видеозвонка не подходит.

1. На компьютере выполните `npm start`
2. На телефоне откройте ссылку **Интернет** из консоли сервера (или LAN HTTPS)
3. Разрешите камеру и микрофон
4. Создайте/войдите в комнату

> Если браузер ругается на сертификат LAN HTTPS — нажмите «Дополнительно» → «Перейти на сайт»,  
> либо используйте туннель-ссылку (у неё обычный доверенный HTTPS).

## Переменные окружения

Скопируйте `.env.example` при необходимости:

| Переменная   | Описание                                              |
|-------------|--------------------------------------------------------|
| `PORT`      | Порт сервера (по умолчанию `3000`)                     |
| `HOST`      | Хост bind (по умолчанию `0.0.0.0`)                     |
| `XAI_API_KEY` | Опционально: SpaceXAI/xAI для AI-резюме в отчёте    |

## Как пользоваться

1. Создайте комнату (по желанию с паролем) или войдите по ID / ссылке `/?room=ID`
2. Разрешите камеру и микрофон
3. Пригласите коллег ссылкой
4. В панели: чат, участники, транскрипция, права
5. Запись и отчёт скачиваются локально на ваш компьютер

## Стек

- Node.js, Express, Socket.IO (сигналинг и комнаты)
- WebRTC mesh (STUN)
- Progressive Web App (manifest + service worker)
- Web Speech API (транскрипция)
- MediaRecorder (запись)
- Опционально SpaceXAI (`grok-4.5`) для резюме отчёта
